# Original Last Call demo segments

orbit.mp4, ocean.mp4 and arcade.mp4 are original procedural animations generated locally by scripts/generate-demo-media.mjs for this project. Each is 18 seconds, 960 × 540, H.264 MP4, with no audio track. No external video footage or audio is included.

These are labeled original silent demo segments throughout the curator and playback views. They are not video recommendations and do not demonstrate AI analysis. The app uses the checked-in files and requires no FFmpeg runtime. FFmpeg is only an optional authoring tool for regenerating these assets.

Curator approval is required separately for every show, including these bundled segments. Stop and restart the show before replacing media so previous approvals cannot be mistaken for review of a replacement.
